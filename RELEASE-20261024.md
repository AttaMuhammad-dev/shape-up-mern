## Updating private database access

Change the Production `MONGO_URI` privately in Vercel after rotating the Atlas user password, and redeploy. Use the dedicated `shape_up_demo` database; never commit a real URI. If another application shares the Atlas user, its connection credential must be updated separately too. Vercel's write-only secret protection is intentional: do not deploy an endpoint to extract a saved secret.
